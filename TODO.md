# Product backlog

This backlog captures the next product opportunities for TabTether.

- [x] Search, tags, and filters — find activities by name, page, or domain and
      organize them with reusable tags.
- [x] Archive instead of delete — hide completed activities while preserving
      their history, with restore support.
- [x] Durable offline sync queue — retain location updates during a temporary
      server outage and replay the newest update for each activity when sync returns.
- [x] Collections / workspaces — group activities into projects with notes and
      a pinned next activity.
- [x] Resume workflow — one action to open an activity on this device and take
      ownership, including a keyboard shortcut or command palette entry.
- [x] Richer activity history — add search, timestamps, return-to-this-point,
      and a navigable timeline.
- [x] Privacy retention controls — configurable 7/30/90-day retention and
      per-activity private mode.
- [x] Share and export — export an activity as JSON, Markdown, or links, then
      consider opt-in sharing.
- [x] Activity health indicators — show stale activities, offline devices,
      ownership conflicts, and sync failures with recovery actions.
- [x] Bulk actions — select multiple activities to archive, delete, tag, move,
      or clear history.
