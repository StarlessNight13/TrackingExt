# Extension-only cutover

TrackingExt now starts in local-only mode and offers cloud database sync directly from the extension. New users no longer need a TrackingExt account, application server, or web dashboard.

The temporary legacy migration connector and maintenance server have been removed.

## Included

- Local-first tracking with IndexedDB caching
- Optional Turso/libSQL cloud database sync
- Optional direct LAN mode
- Cloud health, retries, conflict visibility, import, and export
- Groups, devices, history, and settings managed in the extension dashboard
